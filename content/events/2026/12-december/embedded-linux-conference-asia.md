# Embedded Linux Conference Asia

Embedded Linux Conference (ELC) has been the premier, vendor-neutral technical conference for companies and developers using Linux in embedded products since 2005. The event brings together user-space developers, system architects, and industry experts to collaborate, exchange knowledge, and advance solutions for embedded systems, connected devices, and industrial IoT.
